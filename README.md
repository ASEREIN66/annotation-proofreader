# 标注校对助手（浏览器插件）

> 面向数据标注场景的校对工具：在任意网页选中一段文字，点"校对"，几秒内给出**错别字、歧义词、标点符号、语病、逻辑问题**清单。
> 本地规则与大模型双引擎，支持公有云接口和公司内网模型一键切换。

**⬇ [点此下载插件 v1.1.3](https://aserein66.github.io/annotation-proofreader/annotation-proofreader-v1.1.3.zip)**　·　**[在线介绍页](https://aserein66.github.io/annotation-proofreader/)**　·　支持 Chrome / Edge 116 及以上版本

## 能查出什么

只指出确实有问题的地方，不过度润色；原文无误时直接告诉你"未发现错误"。平台固定字段名、标签名不算错。

| 类别 | 检查内容 | 示例 |
|---|---|---|
| 错别字 | 同音字、形近字、多字漏字 | "按装" → "安装" |
| 歧义词 | 容易被误解成别的意思的用词 | "权利" → "权力"（附歧义原因） |
| 标点符号 | 中英文混用、全半角、引号括号不配对 | "熟练," → "熟练，" |
| 语病 | 搭配不当、成分残缺、语序不当 | "凯旋而归" → "凯旋" |
| 逻辑问题 | 前后矛盾、因果不当、表述歧义 | 问题描述 + 修改建议 |

## 怎么用

1. 在网页上选中一段文字，旁边会出现蓝色"**校对**"按钮
2. 点一下，选区旁弹出一句话总结：`共发现 3 处问题（其中错别字 2 处、标点 1 处）`
3. 点"**查看详情**"，右侧侧边栏按五类列出全部问题，每条都能一键复制修改建议

也可以点浏览器工具栏的插件图标打开侧边栏，直接粘贴文本校对。

## 安装（约 3 分钟）

插件暂未上架应用商店，需要用"开发者模式"手动加载：

1. **下载并解压**：点上方下载链接，把 zip 解压到一个固定位置（路径里最好不要有中文）。**解压出的文件夹不要删除或移动**，否则插件会失效
2. **打开扩展程序页**：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
3. **开启开发者模式**：Chrome 在页面右上角；Edge 在页面左侧栏下方（叫"开发人员模式"）
4. **加载插件**：点"加载已解压的扩展程序"（Edge 叫"加载解压缩的扩展"），选择解压出来的 `annotation-proofreader` 文件夹本身
5. **配置模型**：右键工具栏上的插件图标 → 选项 → 选一个模型服务，填入**你自己的**接口密钥 → 点"授权该站点访问" → 点"测试连通性"，看到"连接成功"即可

> **装完记得刷新网页**：插件安装或更新后，已经打开的网页要按 `Cmd/Ctrl + R` 刷新一次，"校对"按钮才会出现。

## 设计亮点

- **双引擎**：本地规则层离线运行、零成本，先筛掉常见错别字和标点问题；大模型层负责歧义、语病、逻辑这类需要理解语义的问题
- **公有云与内网可切换**：预置 DeepSeek、通义千问、智谱、豆包，也可以填任意兼容接口或公司内网模型地址，切换只改配置、不改代码
- **敏感数据模式**：开启后插件在代码层面禁止把文本发往公有云，只允许走内网模型，适合处理客户委托数据
- **规则层零误报优先**：拿不准的问题宁可不报，交给大模型判断，避免标注员被误报打断

完整的产品需求与设计取舍见 [产品需求文档](docs/PRD.md)。

## 常见问题

**不填接口密钥能用吗？**
能，但只有本地规则层生效，主要查常见错别字和标点。歧义词、语病、逻辑问题需要配置大模型。以 DeepSeek 为例，校对一段 500 字文本约千分之二元。

**接口密钥从哪里获取？**
到对应厂商的开放平台注册（如 DeepSeek 开放平台、阿里云百炼），在控制台创建密钥后粘贴到插件设置页。请使用自己的密钥。

**提示"扩展已更新，请刷新此页面"？**
插件刚被重新加载过，当前网页里还是旧代码。点面板里的"立即刷新页面"，或按 `Cmd/Ctrl + R` 刷新即可。

**点插件图标没有出现侧边栏？**
确认浏览器版本在 116 及以上。版本没问题的话，到扩展程序页点插件卡片上的刷新按钮，再试一次。

**我的标注数据会被上传吗？**
本地规则层完全离线。启用大模型后，选中的文本会发送到你配置的模型接口。处理客户委托或未公开数据时，请开启"敏感数据模式"并使用公司内网模型，同时遵守所在公司的数据安全规定。

**支持哪些浏览器？**
Chrome 116 及以上已实测通过；Edge 116 及以上按官方文档支持同样的能力，可按上面步骤安装。Firefox、Safari 暂不支持。

## 目录结构

```
annotation-proofreader/
├── manifest.json        # 插件清单
├── src/
│   ├── background/      # 后台服务：请求出口、消息路由、报告暂存
│   ├── content/         # 页面脚本：浮动按钮、简版结果面板
│   ├── sidepanel/       # 侧边栏：按五类分组展示完整报告
│   ├── options/         # 设置页：后端切换、密钥、敏感模式
│   └── lib/             # 规则引擎、后端适配、提示词、报告合并
├── icons/               # 插件图标
├── docs/                # 在线介绍页（GitHub Pages）、产品需求文档、配图、安装包
└── tools/               # 图标生成脚本与离线测试
```

## 已知限制

- 侧边栏需要通过点击"查看详情"或插件图标打开（浏览器要求必须由用户点击触发）
- 大模型输出依赖模型遵守指定格式，极少数情况下会返回不合规文本，插件会展示原始输出供人工复核
- 一键替换已移除：分类输出没有字符级定位，强行替换容易错位，统一改为复制建议

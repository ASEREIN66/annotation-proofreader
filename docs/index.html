检查五类问题

只指出确实有问题的地方，不过度润色；原文无误时直接告诉你"未发现错误"。平台固定字段名、标签名不算错。

错别字

同音字、形近字、多字漏字

"按装" → "安装"
歧义词

容易被误解成别的意思的用词

"权利" → "权力"（说明原因）
标点符号

中英文混用、全半角、引号括号不配对

"熟练," → "熟练，"
语病

搭配不当、成分残缺、语序不当

"凯旋而归" → "凯旋"
逻辑问题

前后矛盾、因果不当、表述歧义

问题描述 + 修改建议

为什么好用

悬浮面板只给一句话总结，点"查看详情"在侧边栏看完整清单，不打断标注节奏。

双
双引擎校对

本地规则层离线运行、零成本，先筛掉常见错别字和标点；大模型层负责歧义、语病、逻辑这类需要理解语义的问题。

切
公有云与内网随时切换

预置 DeepSeek、通义、智谱、豆包等接口，也可填任意兼容接口或公司内网模型地址，改配置不改代码。

密
敏感数据模式

开启后插件在代码层面禁止把文本发往公有云，只允许走内网模型，适合处理客户委托数据。

安装步骤（约 3 分钟）

插件暂未上架应用商店，需要用"开发者模式"手动加载，按下面五步操作即可。

下载并解压

点上方"下载插件"，把 zip 解压到一个固定位置（建议路径里不含中文，例如 ~/Documents/plugins）。解压后的文件夹不要删除或移动，否则插件会失效。

打开扩展程序页

Chrome：地址栏输入 chrome://extensions 并回车。
Edge：地址栏输入 edge://extensions 并回车。

开启开发者模式

Chrome：打开页面右上角的"开发者模式"开关。
Edge：打开页面左侧栏下方的"开发人员模式"开关。

加载插件

Chrome 点"加载已解压的扩展程序"，Edge 点"加载解压缩的扩展"，选择解压出来的 annotation-proofreader 文件夹（选文件夹本身，不要进到里面选文件）。

配置模型并测试

点浏览器工具栏的拼图图标，把"标注校对助手"固定到工具栏 → 右键插件图标选"选项" → 选择一个模型服务，填入你自己的接口密钥 → 点"授权该站点访问" → 点"测试连通性"，看到"连接成功"即可。

使用前记得刷新页面：插件安装或更新后，已经打开的网页需要按 Cmd/Ctrl + R 刷新一次，悬浮"校对"按钮才会出现。

常见问题

遇到问题先看这里。

不填接口密钥能用吗？

能用，但只有本地规则层生效，主要能查出常见错别字和标点问题。歧义词、语病、逻辑问题需要大模型，必须配置接口。以 DeepSeek 为例，校对一段 500 字文本的费用大约是千分之二元。

接口密钥从哪里获取？

到对应模型厂商的开放平台注册（如 DeepSeek 开放平台、阿里云百炼），在控制台创建接口密钥后粘贴到插件设置页。请使用自己的密钥，不要共用他人的。

提示"扩展已更新，请刷新此页面"怎么办？

说明插件刚被重新加载过，当前网页里还是旧代码。点面板里的"立即刷新页面"按钮，或按 Cmd/Ctrl + R 刷新即可。

点插件图标没有出现侧边栏？

确认浏览器版本在 116 及以上（Chrome 地址栏输入 chrome://settings/help，Edge 输入 edge://settings/help 查看）。如果版本没问题，到扩展程序页点插件卡片上的刷新按钮，再试一次。

我的标注数据会被上传吗？

本地规则层完全离线。启用大模型后，选中的文本会发送到你配置的模型接口。处理客户委托或未公开数据时，请开启"敏感数据模式"并使用公司内网模型，同时遵守所在公司的数据安全规定。

支持哪些浏览器？

Chrome 116 及以上已实测通过；Edge 116 及以上按微软官方文档支持同样的能力，可按上面写的 Edge 步骤安装。360、QQ 等国产浏览器内核版本可能偏旧，不保证可用；Firefox、Safari 暂不支持。
